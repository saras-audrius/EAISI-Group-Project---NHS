# Simple GitHub Desktop & VS Code Workflow

**Download GitHub Desktop:** https://desktop.github.com/

## Steps:

### 1. Clone a Repository
- Open GitHub Desktop
- Click **File → Clone Repository**

<img width="989" height="639" alt="image" src="https://github.com/user-attachments/assets/ed27b73a-5723-4681-a7e1-cc989e9f3dda" />

- Select the repository from your list (or paste the URL)
- Choose where to save it on your computer
- Click **Clone**

<img width="915" height="631" alt="image" src="https://github.com/user-attachments/assets/30458a38-8164-4299-adb0-99980bd0ce16" />

### 2. Open in VS Code
- In GitHub Desktop, left-click the**Repository → Open in Visual Studio Code**

<img width="952" height="645" alt="image" src="https://github.com/user-attachments/assets/8ee6580c-1b82-40f5-9442-f0fc959e849b" />

### 3. Create a New Branch
- In VS Code, look at the bottom-left corner
- Click on the branch name ("master")
<img width="749" height="1169" alt="image" src="https://github.com/user-attachments/assets/8c2335da-e829-4915-bf6a-dc82b4d93bc1" />

- Click **+ Create new branch**
<img width="1325" height="509" alt="image" src="https://github.com/user-attachments/assets/c90bfd93-54b3-41c4-b857-85be2b27494e" />

- Name your branch (e.g., "data-exploration-audrius")
- Press Enter

### 4. Code
- Make your changes in VS Code
- Save your files (CTRL+S or CMD+S)

### 5. Commit Your Changes
- Click on the source control logo
- You'll see your changed files listed
- Write a commit message in the summary box (e.g., "Added login feature")
- Click **Commit to [your-branch-name]**

<img width="594" height="901" alt="image" src="https://github.com/user-attachments/assets/d26ea470-4304-4898-ab7f-b13d98e3bd58" />

### 6. Push Your Branch
- Click **Publish branch** (or **Push origin** if already published)

### 7. Create Pull Request
- In GitHub Desktop, click **Branch → Create Pull Request**
- This opens GitHub in your browser
- Add a description if needed
- Click **Create Pull Request**

### 8. After Merge
- Once approved and merged, go back to GitHub Desktop
- Switch to the main branch (bottom-left corner → select "main")
- Click **Repository → Pull** to update your local main branch
- Click **Branch → Delete** and select your old branch

Done! 🎉
